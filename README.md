# VocabCli

考研英语红宝书单词学习工具——从 PDF 提取词条，在命令行中交互式背单词。

## 项目背景

本工具围绕「2027 考研英语红宝书」设计，红宝书覆盖约 **6,550 个考研核心词汇**。工具分为两个部分：

1. **PDF 解析**：从红宝书 PDF 中自动提取单词与释义，输出结构化 JSON。
2. **命令行背词**：在终端中以卡片翻页的方式浏览、记忆单词。

## 项目结构

```
VocabCli/
├── script.py                          # PDF 解析脚本
├── word_cli.py                        # 命令行背词脚本
├── requirements.txt                   # Python 依赖
├── words_pdf/                         # 原始 PDF 文件（不纳入版本管理）
│   ├── 2027考研英语红宝书-不背单词正序版.pdf
│   └── 2027考研英语红宝书-不背单词乱序版.pdf
├── words_json/                        # 解析后的 JSON 词库
│   ├── 2027考研英语红宝书-不背单词正序版.json
│   └── 2027考研英语红宝书-不背单词乱序版.json
└── debug/                             # 解析调试输出（自动生成）
```

## 依赖安装

```bash
pip install -r requirements.txt
```

唯一外部依赖是 **[PyMuPDF](https://pypi.org/project/PyMuPDF/)**（`fitz`），用于读取 PDF 文本。

## 使用方式

### 1. 提取 PDF → JSON

确保 `words_pdf/` 目录下已放入红宝书 PDF 文件，然后运行：

```bash
python script.py
```

脚本会自动处理 `words_pdf/` 下所有 `.pdf` 文件，将提取结果保存到 `words_json/` 目录，文件名与 PDF 对应。

输出示例：

```
处理: 2027考研英语红宝书-不背单词正序版.pdf
  第 1/XXX 页，累计 50 条
  第 2/XXX 页，累计 100 条
  ...
已保存到 words_json/2027考研英语红宝书-不背单词正序版.json，共 6550 条
```

#### JSON 输出格式

每个词条结构如下：

```json
{
  "page": 1,
  "index": 1,
  "word": "abandon",
  "meaning": "v. 放弃；遗弃"
}
```

### 2. 命令行背词

```bash
python word_cli.py
```

交互界面：

```
进度: 1/6550  页码: 1
----------------------------------------
单词: abandon

[ 回车下一个 | 输入数字跳转 | q 退出 ]
```

操作说明：

| 按键 | 行为 |
|------|------|
| `回车`（首次） | 显示当前单词释义 |
| `回车`（再次） | 切换到下一个单词（隐藏释义） |
| 输入数字 | 跳转到指定序号的单词 |
| `q` | 退出 |

## PDF 解析原理

PDF 排版复杂，脚本采用了针对红宝书排版特点的解析策略：

- **页眉/页脚过滤**：基于关键词（书名、页码格式等）自动清除噪音行。
- **双模式单词识别**：
  - **一行模式**：`1001 sensitive`（序号 + 空格 + 单词在同一行）。
  - **两行模式**：序号和单词分别占一行（部分页面排版所致）。
- **释义区解析**：以数字序号作为锚点，将后续非数字行合并为释义文本。
- **顺序保证**：同一页内的单词与释义通过序号（`index`）进行匹配，确保一一对应。
- **调试模式**：解析失败时自动将中间结果写入 `debug/` 目录，方便排查。

## 注意事项

- PDF 文件体积较大（正序约 16 MB，乱序约 15 MB），建议通过 `.gitignore` 排除，不纳入版本管理。
- 命令行背词脚本默认读取**正序版** JSON。如需切换到乱序版，修改 `word_cli.py` 中 `WORD_FILE` 变量即可。
- 解析脚本依赖 PDF 的排版格式。若红宝书版本更新导致排版变化，可能需要调整正则表达式或解析逻辑。
