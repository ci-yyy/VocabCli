# 不背单词 · PDF 背词助手

从 **不背单词 App** 导出的 A4 默写格式 PDF 中提取单词与释义，在终端中交互式背词。

> 如果你用不背单词 App 背单词，可以导出 A4 默写纸 PDF，丢进这个工具就能在命令行里刷词，不必盯着手机。

---

## 环境依赖

运行本工具需要：

1. **Python 3.8 或更高版本**
   - Windows 用户：从 https://python.org 下载安装，安装时勾选 "Add Python to PATH"
   - macOS 用户：系统自带 Python 3，或 `brew install python`
   - 验证方法：打开终端（命令行）输入 `python3 --version`，显示版本号即为正常

2. **PyMuPDF**（Python 库，用于读取 PDF）
   安装方法见下方教程。

---

## 详细使用教程

### 第一步：下载项目

将本项目下载到你的电脑上，进入项目目录。

### 第二步：安装依赖

打开终端（命令行），进入项目目录，运行：

```bash
pip install -r requirements.txt
```

> 如果提示 `pip` 不是内部或外部命令，尝试 `pip3 install -r requirements.txt`

安装成功会显示类似 `Successfully installed PyMuPDF-xxx` 的信息。

### 第三步：导出并准备 PDF

**在不背单词 App 中导出 A4 默写纸：**

1. 打开不背单词 App，进入你正在学的词书
2. 点击右上角「…」→「默写」
3. 选择 **A4 默写纸** 格式，导出 PDF
4. 将导出的 PDF 文件放入项目目录下的 `words_pdf/` 文件夹（如果没有就手动新建一个）

> ⚠️ 本工具仅适配不背单词 App 导出的 **A4 默写格式** PDF。其他格式（如标准排版、左英右中等）的 PDF 无法正常提取。

### 第四步：初始化词库

```bash
python init.py
```

> Windows 用户如果提示 `python` 不是命令，请用 `python3 init.py`

程序会扫描 `words_pdf/` 文件夹中的 PDF，列出文件列表让你选择：

```
在 words_pdf/ 中找到以下 PDF 文件：

  1. 考研词汇_乱序版.pdf  (15.5 MB)
  2. 六级词汇_正序版.pdf  (12.3 MB)

请选择要转换的文件 [1-2]:
```

输入数字（如 `1` 或 `2`），回车确认。程序开始提取单词：

```
正在转换: 考研词汇_乱序版.pdf
  第 1/330 页，累计 50 条
  第 2/330 页，累计 100 条
  ...
```

等待提示 **初始化完成**，即可进入下一步。

### 第五步：开始背词

```bash
python word_cli.py
```

看到主菜单：

```
================================================
        📚 不背单词 · 背词助手
================================================

  当前词库: 考研词汇_乱序版.pdf
  总词库: 6591 词
  生词本: 0 词

  1. 刷词模式  — 浏览全部单词，按 s 标记生词
  2. 生词模式  — 复习已标记的生词，按 d 移出
  q. 退出
```

输入 `1` 或 `2` 选择模式。

#### 刷词模式（推荐先刷一遍）

```
📖 刷词模式  进度: 1/6591  页码: 1
--------------------------------------------------
单词: panorama

[ 回车显示/下一个 | s 标记生词 | 数字跳转 | q 退出 ]
```

| 操作 | 效果 |
|------|------|
| 按 **回车**（第一次） | 显示这个单词的中文释义 |
| 按 **回车**（第二次） | 跳到下一个单词 |
| 按 **s** | 把这个单词加入生词本（表示还不会） |
| 输入**数字**（如 `500`） | 直接跳转到第 500 个单词 |
| 按 **q** | 退出 |

> 💡 **背词建议**：先看单词，想一下什么意思，再按回车看释义。不会的按 `s` 收集起来，一轮刷完再集中复习生词。

#### 生词模式（第二轮复习）

```
🔁 生词复习  进度: 1/12  页码: 15
--------------------------------------------------
单词: ambiguous

[ 回车显示/下一个 | d 移出（掌握了）| 数字跳转 | q 退出 ]
```

| 操作 | 效果 |
|------|------|
| 按 **回车** | 显示释义 / 跳到下一个 |
| 按 **d** | 这个词已经掌握了，从生词本移出 |
| 输入**数字** | 跳转 |
| 按 **q** | 退出 |

## 常见问题

**Q: 提示「尚未初始化词库」怎么办？**
还没有运行初始化。请先运行 `python init.py` 选择并转换词库。

**Q: 想换成另一本词库？**
重新运行 `python init.py`，选择另一个 PDF 即可。配置会自动更新，生词本不受影响。

**Q: 生词会丢失吗？**
不会。生词保存在 `data/hard_words.json`，关闭终端再打开数据还在。

**Q: 换电脑了怎么迁移？**
拷贝 `data/` 目录到新电脑的项目中即可保留生词本。词库 JSON 重新运行 `init.py` 生成。

**Q: 按键没反应？**
确认输入法切换到了英文状态。

**Q: 不背单词导出时有哪些选项？**
进入 App → 词书 → 右下角导出→ 选择 **A4 默写纸** 格式导出即可。其他样式（如标准排版）暂不支持。

**Q: 支持其他 App 导出的 PDF 吗？**
本工具专门为不背单词的 A4 默写格式编写，其他 App 或其他排版格式无法保证正确解析。
